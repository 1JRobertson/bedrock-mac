## Verified fixes

- **File preservation:** bundled-script refresh, update journals and prefix setup
  markers opened predictable `.new` files. Existing files were overwritten;
  symlinks could redirect writes and become the installed script/marker. Unique
  exclusive staging now preserves those files and atomically replaces only the
  intended destination. Failed replacement retains the original destination.
- **Installation ownership:** source startup used checkout locks/build receipts
  while imported modules honored an inherited `BEDROCK_HOME`. It now pins the
  complete source flow to the checkout and clears inherited `BEDROCK_BUNDLE`.
- **Source retry:** changed authoritative helper inputs could fail verification
  against stale generated Xodus examples before the rebuild step. Those generated
  copies now refresh before verification; patches and pinned sources stay checked.
- **Cancellation:** TERM/HUP could leave detached source-build jobs running.
  Startup now unwinds through its existing owned-process-group cleanup.
- **DMG output:** creation previously wrote directly to the final path with
  overwrite enabled, and failed creation could leave a retry-blocking image.
  It now creates/verifies privately and publishes without replacing a racing
  output. Hashing uses bounded reads. Receipt metadata comes from the copied,
  signature-verified staged app rather than the mutable source app.
- **Private update data:** game/prefix backups and recovery directories were
  missing from Git ignores. They are now ignored and explicitly rejected by
  the source exporter, including temporary recovery-directory prefixes.
- **Installer transport:** Homebrew's bootstrap curl now ignores user `.curlrc`
  settings so they cannot silently weaken the explicit TLS policy.
- **Newcomer docs:** README now starts with the shipped `Start.command` source
  setup, explains local compilation and data paths, and separately describes
  building an app. A stale graphics-to-gameplay evidence link now targets the
  stability record. Compatibility retains the maintainer's M1 Air/16 GB working
  report and 10+ hours of Xbox/PlayStation play on M4 Pro/24 GB, with the limits
  of those reports stated separately from artifact qualification.

## Validation

The five focused Python modules passed **120 tests**: startup 18, onboarding 42,
standalone session 29, packaging 17, and source export 14. These use synthetic
files/backends and owned subprocesses; they do not access Microsoft or Keychain.
Shell syntax, relative documentation links, source export, checksum inventory,
Git ignore paths and whitespace are checked separately.

Initial full-suite attempts were blocked by the desktop app's 8 GiB footprint
threshold and the shared heavy-QA lock. Once memory was safe, the guarded full
suite passed on macOS with Python 3.9.6: **349 tests run, 5 skipped** in 6.060 s.
Those five notice-collector tests require Python 3.11+; all five separately
passed on the installed Python 3.14.5. A complete 3.14 suite attempt was refused
by the occupied shared lock. These results provide local coverage; hosted CI
has not passed on this branch. The guard was not bypassed and no unrelated
process was stopped.
